# いつかやるリスト

現在のロードマップ完了を妨げない改善候補を記録する。着手時期が決まった項目は、実装ロードマップまたは該当フェーズの仕様へ移す。

## ComfyUIワークフローの整理

- [ ] `comfyui_workflows`内の各ワークフローについて、全ノードの役割と依存関係を確認する
- [ ] コピペ元から残った未使用ノード、重複処理、不要なモデル読み込みおよび過剰な中間処理を特定する
- [ ] LoRA Makerが差し替える入力と回収する出力を分かりやすく整理する
- [ ] 不要なカスタムノード依存を減らせるか検討する
- [ ] 整理前後で出力形式、品質、処理時間およびVRAM使用量を比較する
- [ ] 整理後もAPI用JSONとして動画生成、画像拡大、Taggerの最小実行試験を行う

現状のワークフローは、既存のものをコピーしてブラックボックス的に利用しており、不要な処理が含まれている可能性がある。ただし、現時点では3種類ともAPI実行と出力取得に成功しているため、初期実装を止める課題とはしない。
